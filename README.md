# Worktree Review Has Moved

Worktree Review is now maintained as a bundled VS Code extension in the
[shellos repository](https://github.com/zfan2356/shellos/tree/main/editor/extensions/worktree-review).

Install it from a shellos checkout:

```bash
./scripts/install-worktree-review.sh
```

For a remote Tode extension host:

```bash
./scripts/install-worktree-review.sh <ssh-alias>
```

This repository is retained only as a historical pointer and receives no
further development.
